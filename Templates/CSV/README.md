# CSV templates

Use these header-only templates for supported bulk changes:

- [Bulk User Edits](Bulk-User-Edits-Template.csv)
- [Bulk Group Members](Bulk-Group-Members-Template.csv)
- [Bulk SharePoint Access](Bulk-SharePoint-Access-Template.csv)

UserManagement-Example.csv is a separate synthetic example, not the blank Bulk
User Edits template. Do not assume every importer accepts its schema or rows.

Make and populate a working copy outside the toolkit repository. Never commit real
customer data or add populated rows to the shipped blank templates.

See [Bulk CSV template guidance](../../Documentation/Bulk-CSV-Templates.md).
